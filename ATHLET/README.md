# ATHLET — магазин спортивного питания (.NET MAUI, C#, XAML)
Запуск: Visual Studio 2022 с рабочей нагрузкой «Разработка мобильных приложений на .NET» → открыть Athlet.csproj → выбрать Android-эмулятор → F5.
Данные: SQLite (athlet.db3 в AppDataDirectory), каталог заполняется тестовыми данными при первом запуске.
